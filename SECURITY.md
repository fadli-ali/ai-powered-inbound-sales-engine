# Security and Privacy

## Published Data

This repository contains only fictional lead information created for portfolio testing.

## Excluded Information

The repository intentionally excludes:

- API keys and access tokens
- OAuth credentials
- Private webhook URLs
- HubSpot portal identifiers and private account configuration
- Make scenario exports containing connections or secrets
- Real prospect or employer data

## Operational Safeguard

The workflow prepares an outbound draft but does not send it. Every message requires human review, editing, and approval.

## Reporting a Concern

If a credential or sensitive identifier is ever committed accidentally, revoke or rotate it immediately and remove it from the repository history before continuing to use the integration.
